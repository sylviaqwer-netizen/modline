# 墨斗 Modline 官网

五幕滚动演示。页面使用预设案例，不调用实时 AI。

## 本地预览

在 `website/` 目录：

```bash
npm start
```

不需要 `npm install`。终端会打印本地地址，默认是 http://127.0.0.1:4173 。端口被占用时会向后尝试。按 `Control + C` 停止。

也可以在仓库根目录运行 `npm start`，或直接用浏览器打开 `index.html`。

## 交互

宽屏、足够高、并且系统没有打开「减少动态效果」时，演示区会粘在视口里：向下滚动依次经过问题、想法、连接、论证、表达，向上回看。相位切换带一点滞后，避免滚轮在分界线上来回抖动。快速滑动会等停稳后再换一幕，减少中途连跳。

触控设备、较矮窗口，或开启减少动态效果时，不劫持滚动。用步骤标签、上一幕 / 下一幕、底部进度点切换；触控还可以在演示区左右滑动。

`npm test` 检查滚动相位的纯逻辑。

## 文件

- `index.html`：页面结构
- `styles.css`：布局、对比和过渡
- `app.js`：滚动切换、五步演示、提纲导出
- `story-phase.js`：相位滞后与综合时机
- `favicon.svg`：图标
- `start.mjs`：本地静态服务
